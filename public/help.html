Cerebro Help Center

This guide walks you through every major feature of the Cerebro dashboard, including navigation, filters, cards, charts, overlays, and ticket workflows. Use it as a full reference when onboarding or troubleshooting.

Navigation

  • Overview is the triage surface for what needs attention now.
  • Business Metrics is the longitudinal PM view (weekly/monthly signals).
  • Click the Cerebro text in the top bar to return to Overview.
  • Use the page-specific filters and cards to deep-link into tickets.

Top Bar Actions

  • Last updated + refresh icon: refreshes data and updates the timestamp.
  • The timestamp is fixed until you refresh again.
  • Help Center: opens this guide in a new tab.
  • Insights button: opens an overlay with AI Insights and Emerging Issues.
  • Bell icon: opens the Needs Attention overlay with Active Alerts.
  • Clicking outside any overlay closes it. Use the close button if shown.

Overlays

Insights Overlay

  • Contains AI Insights and Emerging Issues.
  • Emerging Issues compares the last 7 days to the prior 7 days.
  • Hover the info icon to see how Emerging Issues are computed.

Needs Attention Overlay (Bell)

  • Shows Active Alerts (unresolved Critical/High tickets from last 7 days).
  • Clicking an alert filters the dashboard to the relevant issue.
  • Alerts are sorted by urgency (Critical first) and then oldest first.

Overview Page

Global Filters

  • Source filter (all sources or specific channels).
  • Time presets (Last 24h/7d/30d/All/Custom).
  • Custom range uses a date + time picker with a year scroll list.
  • Dragging across the Trends chart also updates the time range.

KPI Cards

  • Ticket Counter, Critical Issues, Theme Distribution, and related KPIs.
  • Info icons explain calculation logic.
  • Counts respect the global Source and Time filters.

Trends Chart

  • Drag across the chart to select a time range.
  • Legend items are clickable to show/hide trendlines.
  • Hover tooltips show exact values at the cursor.
  • Use the expand button to open the chart in a larger view.
  • Click legend text to toggle series visibility (Total, Priority, Negative).

View Tickets Table

  • Columns include Source, Description, Sentiment, Priority, Urgency, User Type, Issue Type, Owner, Created, Updated, Status, and Link.
  • Search is local to the table and applies after filters.
  • Filter panel supports multi-select filters and custom time ranges.
  • Filters apply only after clicking Apply filters.
  • Remove All clears all filters to show all tickets.
  • Sort options include Creation Date, Updated, Urgency, Sentiment, and Priority.
  • Download CSV exports the currently filtered + sorted rows.
  • Filter chips show active selections and can be removed individually.
  • Time filtering uses Created timestamps by default.

Ticket Detail Modal

  • Click any row to open ticket details.
  • Details include sentiment, urgency, user type, tags, created/updated, and link badges.
  • Copyable ticket ID and optional media link are shown when available.
  • Click outside the modal to close.
  • External links (Source/JIRA/Media) open in a new tab.

Business Metrics Page

Global Controls

  • Time range: Last 7d / Last 30d / Last 90d / All / Custom.
  • Source filter for all metrics on the page.
  • Compare to previous period toggle.
  • Custom range uses the same year-scroll datepicker as Overview.

Product Health Snapshot

  • High-Priority Open, Negative Feedback, Resolution Time, Escalating Theme, Ticket Volume.
  • Each card shows current value and delta vs previous period.
  • Deltas are computed using the immediately preceding time window.

Customer Impact & Sentiment

  • Negative Feedback Trend (legend click to show/hide).
  • Segment Impact (P0+P1 only).
  • Themes list with “View tickets” to open the View Tickets modal.
  • “View tickets” respects the current time range and source filter.

Theme & Area Deep Dive

  • Volume Distribution, Priority Heatmap, User Distribution (theme vs user type).
  • Charts have consistent hover styling and legend emphasis.
  • Priority Heatmap shows open tickets by theme and priority band.

Product Quality & Stability

  • Ticket Status by Issue Type, Resolution Rationale, Backlog Aging, Closed Tickets by Priority.
  • Backlog Aging groups open tickets into age buckets (0–3d, 4–7d, 8–14d, 15d+).

Filtering and Sync Behavior

  • Global filters affect KPI cards, charts, and aggregated metrics.
  • Local table filters are independent and applied only after “Apply filters”.
  • When the global filters change, the table syncs to reflect those changes.
  • Removing a chip updates the table immediately.

Common Workflows

  • Investigate a spike: Drag the Trends chart to isolate the time window, then use View Tickets.
  • Find top issues: Use Themes lists and click “View tickets”.
  • Track critical backlog: Use Active Alerts and Backlog Aging.

If anything looks out of sync, hit refresh in the top bar and verify your current filters. For help, return here via Help Center.
